# ECG Physio WiFi 功能测试方案

## 概述

本文档说明如何测试 ECG Physio 的 WiFi 数据传输功能，包括：
1. 协议端到端测试（验证帧格式）
2. 自动化单元测试（无需硬件）
3. 模拟 ESP32 测试（无需真实 ESP32）
4. 硬件集成测试（需要 ESP32）
5. 端到端系统测试

---

## 快速开始

### 测试 1: 协议端到端测试

验证 ESP32 帧格式与上位机解析器匹配：

```bash
cd "4.Python console/V2"
python tests/test_protocol_e2e.py
```

预期输出：
```
[PASS] 帧结构测试
[PASS] CRC 校验测试
[PASS] 协议匹配测试
通过: 3/3
```

### 测试 2: 模拟 ESP32 + 上位机联调

无需真实 ESP32 硬件，使用模拟服务器测试：

**终端 1 - 启动模拟 ESP32：**
```bash
cd "4.Python console/V2"
python tests/mock_esp32_server.py
```

**终端 2 - 启动上位机：**
```bash
cd "4.Python console/V2"
python main.py
```

**操作步骤：**
1. 在上位机中选择 "WiFi 模式" 选项卡
2. 选择 "自定义 TCP 服务器"
3. 输入 IP: `127.0.0.1`, 端口: `12345`
4. 点击 "测试" 验证连接
5. 点击 "连接" 开始接收数据
6. 观察波形显示

## 测试 2: 硬件连接测试（需要 ESP32）

### 前提条件

1. ESP32 已烧录 `softAP` 固件（ECG Bridge 版本）
2. ESP32 已上电
3. 电脑连接到 ESP32 热点 `ECG-Physio`

### 运行方式

```bash
cd "4.Python console/V2"
python tests/test_wifi_hardware.py
```

### 可选参数

```bash
# 指定 IP 和端口
python tests/test_wifi_hardware.py --ip 192.168.4.1 --port 12345
```

### 故障排查

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 无法连接 | ESP32 未运行 | 检查电源，确认固件运行 |
| 无法连接 | 未连接到热点 | 检查电脑 WiFi 连接 |
| 超时 | IP 地址错误 | 尝试 `ping 192.168.4.1` |
| 连接被拒绝 | 端口错误 | 确认固件使用端口 12345 |

## 测试 3: 端到端系统测试

### 完整数据链路测试

```
STM32 (ECG 数据) → USART3 → ESP32 (UART1)
                  → TCP Server → WiFi → PC (Python V2)
```

### 步骤

1. **启动硬件**
   - 连接 STM32 和 ESP32 之间的 UART 线
   - 上电 STM32 和 ESP32

2. **启动 Python 上位机**
   ```bash
   cd "4.Python console/V2"
   python main.py
   ```

3. **配置 WiFi 连接**
   - 点击 "WiFi 模式" 选项卡
   - 选择 "ESP32 AP 模式"
   - 点击 "测试" 验证连接
   - 点击 "连接"

4. **验证数据**
   - 观察波形显示
   - 检查心率/呼吸率检测
   - 对比有线/无线数据一致性

### 验收标准

| 指标 | 标准 |
|------|------|
| 连接成功率 | ≥ 95% |
| 数据完整性 | 无丢失帧 |
| 延迟 | < 100ms |
| 持续运行 | ≥ 1 小时无断开 |

## 常见问题 (FAQ)

**Q: 测试失败 "无法连接到 127.0.0.1"**
A: 这是单元测试，使用本地模拟服务器。确保没有其他程序占用端口 12346-12350。

**Q: 硬件测试显示 "无法连接"**
A: 确认 ESP32 固件已运行，电脑已连接到 ESP32 热点，尝试 `ping 192.168.4.1`。

**Q: 数据速率低于预期**
A: 检查 ESP32 UART 波特率设置（应为 921600），确认 WiFi 信号强度。

**Q: 波形显示不连续**
A: 可能是数据丢失，检查连接稳定性，增加 ESP32 发射功率或缩短距离。
